## Project Overview

VexEngine is a custom C++ renderer with dual backends: OpenGL (`VEX_BACKEND_OPENGL`) and Vulkan (`VEX_BACKEND_VULKAN`). It supports four render modes:

- **Rasterize** — Forward rasterizer, both backends
- **CPU Raytrace** — Software BVH path tracer, CPU-side, both backends
- **GPU Raytrace** — Vulkan hardware ray tracing pipeline (`VK_KHR_ray_tracing_pipeline`)
- **Compute Raytrace** — Vulkan compute shader BVH path tracer

Key directories:

| Path | Purpose |
|------|---------|
| `engine/include/vex/` | Public engine API headers |
| `app/src/` | Application layer, render modes, scene graph |
| `backends/vulkan/` | Vulkan backend implementation |
| `backends/opengl/` | OpenGL backend implementation |
| `shaders/vulkan/` | GLSL → SPIR-V shaders (via glslc) |
| `shaders/opengl/` | GLSL shaders for OpenGL backend |

## IRenderMode Interface

`IRenderMode` is the abstract base for all render modes, declared in `app/src/render_mode.h`. SceneRenderer holds one concrete instance per mode (allocated at `init()`) and routes each frame to the currently active mode via a non-owning `m_activeMode` pointer.

### Virtual Methods

| Method | Signature | When Called | Notes |
|--------|-----------|-------------|-------|
| `init` | `bool init(const RenderModeInitData& init)` | Once at `SceneRenderer::init()` | Copies stable shared resources from `RenderModeInitData` into members. Returns false on error. |
| `shutdown` | `void shutdown()` | At `SceneRenderer::shutdown()` | Releases GPU resources owned by the mode. |
| `activate` | `void activate()` | On mode switch-in | Resets accumulators, marks geom dirty, resets sample counters. |
| `deactivate` | `void deactivate()` | On mode switch-out | Releases GPU scene data no longer needed. |
| `render` | `void render(Scene&, const SharedRenderData&, const FrameChanges&)` | Every frame via `SceneRenderer::renderScene()` | The primary per-frame rendering entry point. |
| `onGeometryRebuilt` | `void onGeometryRebuilt()` | After `SceneGeometryCache::rebuild()` completes | Triggers internal `activate()` + marks geometry as pending upload to GPU. Default: no-op. |
| `resetAccumulation` | `void resetAccumulation()` | On user request or invalidating scene change | Zeroes path tracer sample buffer. Default: no-op. |
| `getSampleCount` | `uint32_t getSampleCount() const` | Editor UI polling | Returns accumulated sample count. Default: 0. |
| `getSamplesPerSec` | `float getSamplesPerSec() const` | Editor UI polling | Exponentially smoothed throughput metric. Default: 0. |
| `reloadShader` | `bool reloadShader()` | On user hot-reload request | Rebuilds the compute/RT shader pipeline. Default: returns false. |

### Supporting Structures

**`RenderModeInitData`** — stable data injected once at `init()`:
- Shared GPU objects: `fullscreenQuad`, `whiteTexture`, `flatNormalTexture`, `meshShader`, `fullscreenRTShader`
- Bloom resources: `bloomFB[2]`, `bloomThresholdShader`, `bloomBlurShader`
- Geometry and raytracing: `geomCache` (`SceneGeometryCache*`), `cpuRaytracer`, `resizeCPUAccumTex` (callback)
- VK-only: `vkRTSettings` (pointer into `GPURaytraceMode::m_settings`)

**`SharedRenderData`** — per-frame data passed to every `render()` call:
- `outputFB`, `outlineMaskFB`, `cpuAccumTex`, `outlineActive`, `enableNormalMapping`
- `showDenoisedResult*`, `drawCalls*`, `maxSamples`, `debugMode`
- `selectedNodeIdx`, `selectedSubmesh`
- Bloom: `bloomEnabled`, `bloomIntensity`, `bloomThreshold`, `bloomBlurPasses`
- Env: `rasterEnvColor`, `rasterEnvMapTex` (GL) / `vkRasterEnvTex` (VK)
- Shadow: `shadowFB`, `shadowLightVP`, `shadowNormalBias`, `shadowEverRendered`
- VK-only: `vkVolumesData`

**`FrameChanges`** — per-frame dirty flags computed by `SceneRenderer::computeFrameChanges()`:
- `cameraChanged`, `dofChanged`, `lightChanged`, `sunChanged`, `envChanged`, `envDataChanged`, `skyboxColorChanged`, `volumesChanged`
- Camera data: `camPos`, `viewMatrix`, `projMatrix`, `sunDir`
- Env data pointers: `glEnvMapData/W/H` (GL) or `vkEnvMapData`, `vkEnvCdfData`, `vkEnvMapW/H` (VK)

## Render Modes

### Rasterize Mode (`RasterizeMode`)

**Purpose:** Real-time Blinn-Phong rasterizer with HDR pipeline, directional shadow maps, bloom, and optional env-map image-based lighting. The only mode available on both backends for interactive preview.

**Backend support:** OpenGL and Vulkan.

**Per-frame rendering loop (`renderWithSelection`):**
1. Resize `m_rasterHDRFB` if viewport changed; on VK, wait idle and rebuild mesh shader pipeline.
2. Bind `m_rasterHDRFB`, clear to skybox color or black.
3. Draw skybox if enabled and not solid color.
4. Bind mesh shader; upload camera, light, sun, shadow, and env uniforms.
5. Iterate all nodes and submeshes: set model matrix and per-material textures, draw mesh.
6. Bloom pass (optional): threshold HDR FB into `bloomFB[0]`, then `N*2` Gaussian blur passes ping-ponging between `bloomFB[0]` and `bloomFB[1]`.
7. Fullscreen tone-map blit: sample HDR buffer through `fullscreenRTShader` (ACES, exposure, gamma), composite outline mask and bloom, write to `outputFB`.

**Geometry rebuild triggers:** None. The rasterizer reads `SceneMesh::mesh` GPU buffers and `modelMatrix` values directly from the scene graph each frame. When `scene.geometryDirty` is true in rasterizer mode, `SceneRenderer::renderScene()` defers the rebuild as `m_pendingGeomRebuild` and applies any `materialDirty` immediately.

---

### CPU Raytrace Mode (`CPURaytraceMode`)

**Purpose:** Progressive CPU-side path tracer. Each frame traces one sample per pixel using a BVH built over the scene's geometry. Accumulation is done in `vex::CPURaytracer` internally; the mode reads back a linear HDR buffer and uploads it to a `Texture2D` (RGBA32F) for fullscreen display.

**Backend support:** OpenGL and Vulkan (backend agnostic — GPU is used only for display).

**Per-frame rendering loop:**
1. Resize `m_cpuRaytracer` to current viewport dimensions.
2. React to `FrameChanges`: reset accumulator on `envChanged`, `lightChanged`, `sunChanged`, `cameraChanged`.
3. Set DoF parameters (aperture, focus distance, right/up basis vectors).
4. If not showing denoised result and sample limit not reached: trace one sample via `m_cpuRaytracer->traceSample()`, measure throughput, read back `getLinearHDR()`, pack to RGBA32F, upload via `raytraceTex->setData()`.
5. Optional bloom pass on accumulation texture.
6. Fullscreen blit through `fullscreenRTShader` (tone mapping, ACES, exposure, gamma).

**Geometry rebuild triggers:** `CPURaytraceMode` does not own geometry. When `SceneGeometryCache::rebuild()` completes, `SceneRenderer::rebuildRaytraceGeometry()` repopulates `m_cpuRaytracer` with the new BVH and triangles. Mode activation on mode-switch resets the accumulator.

---

### GPU Raytrace Mode (`GPURaytraceMode`)

**Purpose:** On OpenGL, wraps `vex::GLGPURaytracer` (compute-shader software path tracer). On Vulkan, wraps `vex::VKGpuRaytracer` (hardware ray tracing pipeline using `VK_KHR_ray_tracing_pipeline`). Progressive accumulation happens in a GPU storage image; the result is displayed via the shared fullscreen shader.

**Backend support:** OpenGL (GL compute path tracer) and Vulkan (HW RT pipeline with BLAS/TLAS).

**Per-frame rendering loop (VK path):**
1. Compare `m_settings` vs `m_prevSettings`; if changed, call `activate()` (reset + clear sample count).
2. If geometry dirty: call `m_raytracer->uploadSceneData()` with packed VK buffers from `m_geomCache`.
3. If viewport changed: recreate output image at new resolution, reset sample count.
4. React to `cameraChanged`, `lightChanged`, `sunChanged`, `dofChanged`, `volumesChanged`: reset accumulator.
5. Build `RTUniforms` struct (288 bytes std140): camera matrices, DOF, light/sun/env parameters, all `VKRTSettings` fields.
6. `m_raytracer->trace(cmd)` → `postTraceBarrier` → increment `m_sampleCount`.
7. Optional bloom pass (threshold → pingpong blur).
8. Composite pass: `fullscreenRTShader` samples accumulation image, applies exposure/gamma/ACES/outline/bloom, writes to `outputFB`.

**Geometry rebuild triggers:** `onGeometryRebuilt()` calls `activate()` (reset accumulator, zero sample count) and sets `m_geomDirty = true`. On next `render()`, `m_geomDirty` triggers `uploadSceneData()`. On `deactivate()` (VK only): `m_raytracer->freeSceneData()` releases TLAS/SSBO allocations.

---

### VK Compute Raytrace Mode (`VKComputeRaytraceMode`)

**Purpose:** Vulkan-only software BVH path tracer running entirely in a compute shader (`pathtracer.comp`). Uses the same CPU BVH and triangle data as the CPU raytracer but dispatches it as a compute workgroup. Shares `VKRTSettings` with `GPURaytraceMode`.

**Backend support:** Vulkan only (`#ifdef VEX_BACKEND_VULKAN`).

**Descriptor bindings (set=0, 11 bindings):**
`UBO(0)`, `BVH(1)`, `TriVerts(2)`, `Lights(3)`, `TexData(4)`, `EnvMap(5)`, `EnvCDF(6)`, `TriShading(7)`, `StorageImage rgba32f(8)` (output), `Albedo rgba32f(9)`, `Normal rgba32f(10)`.

**Per-frame rendering loop:**
1. Upload env map or geometry if dirty or first render.
2. If viewport changed: `createOutputImage(w, h)`, reset sample count.
3. React to scene changes: reset accumulator.
4. Build `VKComputeUniforms` (320 bytes std140): identical layout to `RTUniforms` for the first 288 bytes, plus `triangleCount`, `bvhNodeCount`, padding.
5. `m_vkComputeRaytracer->traceSample(cmd)` → `postTraceBarrier(cmd)`.
6. Optional bloom, then fullscreen composite (same pattern as GPURaytraceMode).

---

## SceneGeometryCache

`SceneGeometryCache` (declared in `app/src/scene_geometry_cache.h`) is a value member of `SceneRenderer` (`m_geomCache`). It centralises all packed geometry: the CPU-side BVH, triangle arrays, texture data, light CDF, and Vulkan-specific SSBOs.

### What It Owns

**CPU data:** `m_rtTriangles` (BVH-reordered), `m_rtBVH`, `m_rtTextures` (capped at `RT_TEX_MAX=1024` per axis), `m_rtLightIndices`, `m_rtLightCDF`, `m_rtTotalLightArea`, `m_rtTriangleSrcSubmesh`, `m_rtTriangleSrcTriIdx`, `m_nodeLocalAABBs`, `m_texturePathToIndex`.

**Vulkan data:** `m_vkTriShading` (13 vec4s / triangle, per-submesh order), `m_vkLights` (packed uint32 array with header), `m_vkInstanceOffsets` (one uint32 per BLAS).

### Public API

| Method | Purpose |
|--------|---------|
| `rebuild(scene, cpuRT, luminanceCDF, progress)` | Full rebuild: pack triangles, build BVH, load textures, build light CDF. Calls `cpuRT.uploadGeometry()`. |
| `buildAccelerationStructures(scene, vkRaytracer, progress)` | VK only: builds per-submesh BLAS and scene TLAS. Must be called after `rebuild()`. |
| `rebuildMaterials(scene, cpuRT, luminanceCDF)` | Patch baseColor/emissive/emissiveStrength for changed submeshes only, rebuild light CDF. Much cheaper than full rebuild. |
| `rebuildLightCDF(luminanceCDF)` | Rebuild only the emissive-triangle CDF. |
| `isReady()` / `isAccelReady()` | Guards for safe access. |
| Read-only accessors | `triangles()`, `bvh()`, `lightIndices()`, `lightCDF()`, `totalLightArea()`, `textures()`, `nodeLocalAABBs()`, `triSrcSubmesh()`, `triSrcTriIdx()`, `vkTriShading()`, `vkLights()`, `vkInstanceOffsets()` |

### Rebuild Triggers

1. **Import (OBJ/GLTF):** `scene.geometryDirty = true` → `rebuildRaytraceGeometry()` on next frame.
2. **Mode switch from Rasterize to RT:** If cache not ready, `setRenderMode()` sets `m_pendingGeomRebuild = true`. `flushPendingGeomRebuild()` triggers rebuild before the first RT frame.
3. **In-frame geometry change (RT mode active):** `scene.geometryDirty = true` → `rebuildRaytraceGeometry()` at top of `renderScene()`.
4. **Material-only change:** `scene.materialDirty = true` → `rebuildMaterials()` (no BVH rebuild).
5. **LuminanceCDF toggle:** `setUseLuminanceCDF()` → `rebuildLightCDF()` + `onGeometryRebuilt()` on all RT modes.
6. **Deletion/addition via command stack:** `CmdAddNode`/`CmdDeleteNode` call `waitIdle()` and manipulate the scene; `scene.geometryDirty` is set, triggering rebuild on next frame.

## Undo/Redo System

Declared in `app/src/command.h`. The system uses the Command pattern: each undoable action is captured as an `ICommand` subclass and managed by `CommandStack`.

### ICommand Interface

```cpp
struct ICommand
{
    virtual ~ICommand() = default;
    virtual void undo(Scene& s, SceneRenderer& r, SelectionState& sel) = 0;
    virtual void redo(Scene& s, SceneRenderer& r, SelectionState& sel) = 0;
};
```

### Concrete Command Types

| Command | Purpose | Stored State |
|---------|---------|--------------|
| `CmdAddNode` | Inserts a single node at a specific flat-vector index. | `NodeSave save`, `insertionIndex`, `parentIndex`, `siblingPos`. Undo deletes via `SceneImporter`; redo re-adds from save. |
| `CmdDeleteNode` | Deletes a subtree rooted at a node. | `vector<NodeSave> subtreeSaves`, `originalIndices`, `rootParentIdx`, `rootSiblingPos`. Calls `waitIdle()` before GPU mutation. |
| `CmdReparent` | Moves a node to a different parent while preserving world-space position. | `nodeIdx`, `oldParentIdx`, `newParentIdx`, `oldSiblingPos`, `oldLocalMatrix`, `newLocalMatrix`. |
| `CmdAddVolume` | Inserts a `SceneVolume` at a specific index. | `SceneVolume vol`, `index`. |
| `CmdDeleteVolume` | Removes a `SceneVolume` from the scene. | `SceneVolume vol`, `index`. |
| `CmdImportUndo` | Wraps a `CmdDeleteNode` with swapped undo/redo semantics for OBJ/GLTF import. | `CmdDeleteNode delCmd`. |
| `CmdSetTransform` | Stores a node local matrix before and after a gizmo drag. | `nodeIdx`, `before` (local matrix), `after` (local matrix). |

### CommandStack Behaviour

`CommandStack` holds two `deque<unique_ptr<ICommand>>`: `m_undoStack` and `m_redoStack`. Maximum undo depth is 50 (`MAX_UNDO`).

| Method | Behaviour |
|--------|-----------|
| `execute(cmd, s, r, sel)` | Calls `cmd->redo()` immediately, pushes to `m_undoStack`, clears `m_redoStack`. |
| `pushUndoOnly(cmd)` | Pushes to `m_undoStack` without calling redo (for already-applied actions: import, gizmo drag-end). Clears `m_redoStack`. |
| `undo(s, r, sel)` | Pops from `m_undoStack`, calls `undo()`, moves command to `m_redoStack`. |
| `redo(s, r, sel)` | Pops from `m_redoStack`, calls `redo()`, moves command to `m_undoStack`. |
| `clear()` | Empties both stacks (called on full scene reload). |

**Keyboard bindings:** `Ctrl+Z` → undo, `Ctrl+Y` → redo, `Ctrl+D` → duplicate selected node, `DEL` → delete node, gizmo drag-end → `CmdSetTransform` via `pushUndoOnly()`.

## Scene Graph

### Structure

```
Scene
 ├── camera         (vex::Camera)
 ├── nodes[]        (vector<SceneNode>)   ← flat array, tree encoded by index links
 │    └── SceneNode
 │         ├── name, center, radius
 │         ├── localMatrix (glm::mat4)    ← relative to parent
 │         ├── parentIndex  (int, -1 = root)
 │         ├── childIndices (vector<int>)
 │         └── submeshes[]  (vector<SceneMesh>)
 │              └── SceneMesh
 │                   ├── name
 │                   ├── mesh             (unique_ptr<vex::Mesh>)
 │                   ├── diffuseTexture   (shared_ptr<vex::Texture2D>)
 │                   ├── normalTexture / roughnessTexture / metallicTexture
 │                   ├── emissiveTexture / aoTexture / alphaTexture
 │                   ├── meshData         (vex::MeshData)  ← CPU copy
 │                   ├── modelMatrix      (glm::mat4)      ← local to node
 │                   └── baseColor, emissiveColor, emissiveStrength,
 │                       materialType, roughness, metallic, alphaClip, IOR
 │
 ├── volumes[]      (vector<SceneVolume>)
 │    └── SceneVolume
 │         ├── name, center, halfSize
 │         ├── density (sigma_t), albedo (vec3 sigma_s/density), aniso (HG g)
 │         └── infinite (bool), enabled (bool)
 │
 ├── skybox         (unique_ptr<vex::Skybox>)
 ├── Lighting: lightPos, lightColor, lightIntensity, sunAzimuth, sunElevation,
 │             sunColor, sunIntensity, sunAngularRadius, showSun, showLight
 └── Environment: currentEnvmap, skyboxColor, envRotation, customEnvmapPath,
                  geometryDirty, materialDirty, showSkybox
```

### Transform Hierarchy

The scene graph is stored as a **flat vector** with parent/child relationships encoded as integer indices. This avoids pointer invalidation on push_back/erase.

**World matrix computation:**
```
Scene::getWorldMatrix(nodeIdx):
    if parentIndex == -1: return node.localMatrix
    else: return getWorldMatrix(parentIndex) * node.localMatrix
```

**Full submesh world matrix** (used in all render passes and gizmo):
```
submeshWorld = scene.getWorldMatrix(nodeIdx) * submesh.modelMatrix
```

**Dirty flag semantics:**
- `scene.geometryDirty = true` — triggers full geometry cache rebuild (BVH, triangles, textures, VK SSBOs). Set on: node add/delete, mesh import, transform change while in RT mode.
- `scene.materialDirty = true` — triggers `rebuildMaterials()` (patch color/emissive, rebuild light CDF). Set on: material property edits in the inspector. In rasterizer mode, geometry dirty is deferred; material dirty is still applied immediately.

## Shaders

## OpenGL Backend

### `bloom_blur.frag` — Fragment

Performs one pass of a separable 9-tap Gaussian blur on the bloom ping-pong framebuffer.

**Inputs/Outputs:**
- `in vec2 TexCoords` — UV from fullscreen quad
- `out vec4 FragColor` — blurred RGB result

**Uniforms:**
- `sampler2D u_image` — source bloom framebuffer
- `bool u_horizontal` — selects horizontal (true) or vertical (false) pass

**Algorithm:**
- Samples the center texel weighted by `weight[0]` (0.2270270).
- Branches on `u_horizontal` to select offset axis.
- Accumulates 4 symmetric tap pairs at ±1..±4 texels, weights from a σ≈1.5 Gaussian kernel (`weight[1..4]`).
- Writes RGB sum with alpha=1; called twice per blur iteration (H then V, ping-pong between `m_bloomFB[0/1]`).

---

### `bloom_threshold.frag` — Fragment

Extracts bright pixels from the accumulated HDR buffer, producing the bloom source image.

**Inputs/Outputs:**
- `in vec2 TexCoords` — UV from fullscreen quad
- `out vec4 FragColor` — thresholded HDR color

**Uniforms:**
- `sampler2D u_hdrMap` — raw accumulation buffer (un-tone-mapped, summed samples)
- `float u_threshold` — luminance cutoff
- `float u_sampleCount` — divides accumulated sum to produce per-sample radiance

**Algorithm:**
- Divides sampled color by `max(u_sampleCount, 1.0)` to normalize the accumulation buffer.
- Computes luminance via Rec. 709 coefficients (0.2126, 0.7152, 0.0722).
- Computes soft-threshold factor: `max(0, brightness - threshold) / max(brightness, 0.0001)`.
- Multiplies color by the factor, so below-threshold pixels go to black and bright pixels ramp in proportionally.

---

### `envmap.frag` — Fragment

Renders the skybox by sampling an equirectangular environment map from a reconstructed world-space ray direction.

**Inputs/Outputs:**
- `in vec2 vScreenPos` — NDC-space xy position from `envmap.vert`
- `out vec4 FragColor` — skybox color

**Uniforms:**
- `mat4 u_inverseVP` — inverse view-projection for ray reconstruction
- `float u_envRotation` — Y-axis rotation offset applied to the azimuth angle
- `sampler2D u_envmap` — equirectangular HDR environment map

**Algorithm:**
- Reconstructs a world-space direction by unprojecting `(vScreenPos, 1, 1)` through `u_inverseVP` and perspective-dividing.
- Converts direction to spherical coordinates: `u = atan(z, x) + rotation`, `v = asin(y)`.
- Wraps u with `fract` to avoid the atan seam; samples with `textureLod(..., 0)` to suppress mip artifacts.

---

### `envmap.vert` — Vertex

Passes through a fullscreen-quad position for the skybox fragment shader.

**Inputs/Outputs:**
- `layout(location=0) in vec2 aPos` — clip-space quad vertex
- `out vec2 vScreenPos` — forwarded to fragment stage
- `gl_Position = vec4(aPos, 1.0, 1.0)` — z=1 places geometry at the far plane

---

### `fullscreen_rt.frag` — Fragment

Composite shader that normalizes the path-traced accumulation buffer, applies tone mapping, bloom, and screen-space outline overlay.

**Inputs/Outputs:**
- `in vec2 TexCoords` — UV from fullscreen quad
- `out vec4 FragColor` — final LDR display color

**Uniforms:**
- `sampler2D u_accumMap` — raw path-traced accumulation (summed HDR samples)
- `float u_sampleCount` — divides the accumulation buffer
- `float u_exposure` — EV offset, applied as `pow(2, exposure)`
- `float u_gamma` — gamma value; output is raised to `1/gamma`
- `bool u_enableACES` — enables ACES filmic tone mapping (Narkowicz fit)
- `bool u_flipV` — flips V coordinate when source has bottom-left origin
- `sampler2D u_outlineMask` — selection outline mask
- `bool u_enableOutline` — enables outline composite
- `sampler2D u_bloomMap` — pre-blurred bloom texture
- `bool u_enableBloom` — enables bloom
- `float u_bloomIntensity` — bloom additive strength

**Algorithm:**
- Optionally flips V for accumulation and outline textures.
- Divides by sample count, multiplies by `pow(2, exposure)`.
- Additively blends bloom in HDR linear space before tone mapping.
- Applies ACES (Narkowicz) or clamp-only tone mapping.
- Applies gamma correction via `pow(c, 1/gamma)`.
- Computes a 5×5 dilation of the outline mask, subtracts the original to isolate the ring, and composites orange (`vec3(1, 0.5, 0)`) over the result.

---

### `fullscreen.frag` — Fragment

Simple pass-through blit shader with optional V-flip for displaying a 2D texture.

**Uniforms:** `sampler2D u_diffuseMap`, `bool u_flipV`

**Algorithm:** Optionally inverts the V component; direct texture fetch with no additional processing.

---

### `fullscreen.vert` — Vertex

Fullscreen-quad vertex shader. Decodes UV from the packed vertex format and outputs it to the fragment stage.

---

### `mesh.frag` — Fragment

PBR mesh fragment shader implementing Cook-Torrance GGX shading with directional shadow maps, environment reflections, and numerous debug modes.

**Inputs/Outputs:**
- `in vec3 vWorldPos, vNormal, vColor, vEmissive`; `in vec2 vUV`; `in vec4 vTangent`
- `out vec4 FragColor`

**Uniforms:**
- Camera/lights: `u_cameraPos`, `u_lightPos`, `u_lightColor`, `u_sunDirection`, `u_sunColor`
- Textures: `u_diffuseMap`, `u_normalMap`, `u_roughnessMap`, `u_metallicMap`, `u_emissiveMap`, `u_envMap`, `u_aoMap`, `u_alphaMap`
- Material overrides: `u_baseColor` (vec3), `u_roughness`, `u_metallic`, `u_emissiveStrength`, `u_emissiveColor`, `u_materialType`, `u_alphaClip`
- Environment: `u_hasEnvMap`, `u_enableEnvLighting`, `u_envColor`, `u_envLightMultiplier`, `u_envRotation`
- Shadows: `u_shadowViewProj` (mat4), `sampler2DShadow u_shadowMap`, `u_enableShadows`, `u_shadowNormalBias`, `u_shadowStrength`, `u_shadowColor`
- Debug/misc: `u_debugMode` (0=none, 1=wireframe, 2=depth, 3=geo normals, 4=UVs, 5=albedo, 6=emission, 7=mat type, 8=roughness, 9=metallic, 10=AO, 11=mapped normals)

**Algorithm:**
- Alpha clip (texture or diffuse alpha < 0.5).
- Debug early-outs: outputs specific buffer contents based on `u_debugMode`.
- Gram-Schmidt TBN normal mapping with bitangent handedness sign.
- Cook-Torrance GGX BRDF (`D_GGX`, `G_Smith`, `F_Schlick`) for point light (quadratic attenuation) and sun (directional).
- Ambient from solid env color + IBL specular lobe from equirectangular env map reflection, roughness-driven mip, with horizon fade.
- PCF 3×3 shadow with normal-offset bias (sin-scaled) and receiver plane depth bias (RPDB via screen-space derivative Jacobian).
- Emissive from vertex color and optional emissive texture, scaled by `u_emissiveStrength`.

---

### `mesh.vert` — Vertex

Transforms mesh vertices to world and clip space, forwarding shading attributes to the fragment stage.

**Inputs:** `layout(location=0..5) in` — aPos, aNormal, aColor, aEmissive, aUV, aTangent

**Uniforms:** `mat4 u_view`, `mat4 u_projection`, `mat4 u_model`

**Algorithm:** Transforms normal via `mat3(transpose(inverse(u_model)))` (non-uniform scale safe); transforms tangent xyz by `mat3(u_model)`, preserves handedness in w.

---

### `outline_mask.frag` — Fragment

Writes a solid white mask for the selected object's pixels into the outline mask framebuffer.

**Algorithm:** `FragColor = vec4(1.0)` unconditionally; depth test provides the silhouette.

---

### `outline_mask.vert` — Vertex

Transforms selected mesh vertices to clip space for the outline mask pass.

---

### `outline.frag` — Fragment

Fills the expanded silhouette geometry with a solid outline color.

**Uniforms:** `vec3 u_outlineColor`

---

### `outline.vert` — Vertex

Extrudes the selected mesh along its normals in clip space to produce the outline shell.

**Uniforms:** `mat4 u_view`, `u_projection`, `float u_outlineWidth`

**Algorithm:** Offsets `clipPos.xy` by `normalize(clipNorm.xy) * u_outlineWidth * clipPos.w`, making the extrusion screen-space-constant regardless of depth after perspective divide.

---

### `pick.frag` — Fragment

Encodes an object ID into RGB channels for CPU readback to implement mouse-click selection.

**Uniforms:** `int u_objectID`, `sampler2D u_diffuseMap`, `bool u_alphaClip`

**Algorithm:** Discards if alpha-clipped; encodes `objectID + 1` (1-based so black = no object) into R=bits[23:16], G=bits[15:8], B=bits[7:0].

---

### `pick.vert` — Vertex

Transforms mesh vertices for the pick/selection framebuffer pass, forwarding UVs.

---

### `shadow.frag` — Fragment

Empty fragment shader for the depth-only directional shadow map pass.

**Algorithm:** `void main() {}` — depth writes happen automatically via the depth attachment.

---

### `shadow.vert` — Vertex

Transforms mesh vertices into the directional light's clip space for shadow map rendering.

**Uniforms:** `mat4 u_lightViewProj`, `mat4 u_model`

**Algorithm:** `gl_Position = u_lightViewProj * u_model * vec4(aPos, 1.0)`.

---

### `pathtracer.comp` — Compute

Software BVH path tracer implementing full physically-based light transport on the GPU compute pipeline (OpenGL Compute Raytrace mode).

**Work group size:** 8×8 threads.

**Bindings (OpenGL SSBO/image):**
- `image2D u_accumImage` (rgba32f, binding 0) — accumulation buffer
- `BVHNodes[]` (binding 0, std430) — BVH node array
- `TriVerts[]` (binding 1, std430) — 3 vec4s per triangle (hot, intersection only)
- `Lights[]` (binding 2, std430) — header (`lightCount, totalLightArea, pad, pad`) + `uint lightRawData[]`
- `TexData[]` (binding 3, std430) — header: texCount, per-tex `{offset,w,h,pad}`, then packed RGBA8 pixels
- `EnvMap[]` (binding 4, std430) — float RGB pixels (raw HDR)
- `EnvCDF[]` (binding 6, std430) — `[H marginal floats][W×H conditional floats][1 total-integral float]`
- `TriShading[]` (binding 5, std430) — 10 vec4s per triangle (cold, hit-only shading data)

**TriShading layout (10 vec4s per tri):**
- `[0]` n0.xyz + roughnessTexIdx; `[1]` n1.xyz + metallicTexIdx; `[2]` n2.xyz + emissiveStrength
- `[3]` uv0.xy + uv1.zw; `[4]` uv2.xy + roughness + metallic
- `[5]` color.xyz + texIdx; `[6]` emissive.xyz + area; `[7]` geoNormal.xyz + normalMapTexIdx
- `[8]` alphaClip + materialType + ior + emissiveTexIdx; `[9]` tangent.xyz + bitangentSign

**Key helper functions:** `hash/rngNext` (PCG RNG), `traceRay` (iterative BVH, 64-entry stack, near-child-first, alpha-clip support), `traceShadowRay` (any-hit early-termination), `sampleVNDF` (Heitz 2018), `ctEvaluate/ctPdf` (GGX BRDF), `sampleEnvMapDirection/envMapPdf` (hierarchical CDF env sampling), `sampleLightPoint` (CDF-based emissive triangle area sampling), `pathTrace` (full iterative path tracing loop).

**`main()` flow:** Bounds-check → seed PCG RNG → AA jitter → `generateRay` → `pathTrace` → firefly clamp → NaN/Inf guard → `imageLoad`/`imageStore` accumulation.

**`pathTrace()` loop:** Optional Russian Roulette → `traceRay` → on miss: add sky/env radiance (MIS) → back-face passthrough → compute normal with optional normal map → sample ARM textures (roughness=G, metallic=B, AO=R) → material dispatch (thin glass, dielectric, mirror, Cook-Torrance GGX) → NEE (emissive triangles, point light, sun, env CDF) with MIS balance heuristic → VNDF specular or cosine diffuse sample for next bounce.

**Volumes SSBO layout (3 vec4s per volume, 1 vec4 header):**
- Header: `volumeData[0].x` = count (as uint bits)
- Per volume at `base = 1 + vi*3`: `[0]` center.xyz + sigmaT; `[1]` halfSize.xyz + g (anisotropy); `[2]` sigmaS.rgb (=albedo×sigmaT) + infinite(0/1)

**Key helper functions:** `rngHash/rngNext` (PCG), `halton(index, base)` (Halton LDS), `ign(vec2)` (Interleaved Gradient Noise, Jimenez 2014), all `triN/UV/V/Color/...` SSBO accessors, `sampleTexture` (hardware sampler2D array with V-flip), `sampleEnvironment` (hardware env map sampler), `sampleEnvMapDirection/envMapPdf` (hierarchical CDF env sampling), `sampleVNDF` (Heitz 2018), `ctEvaluate/ctPdf` (GGX BRDF), `v_volumeCount`, `phaseHG`, `sampleHG`, `rayAABB`.

### `rt.rgen` — RayGen

Hardware ray tracing entry point implementing iterative path tracing over the TLAS.

**Payloads:**
- `layout(location=0) rayPayloadEXT HitPayload g_payload` — primary hit result
- `layout(location=1) rayPayloadEXT uint g_shadowed` — shadow occlusion flag

**`main()` flow:** Bounds-check → seed `g_rngState` → AA jitter (3 modes: PCG, Halton+Cranley-Patterson, IGN+golden-ratio) → `generateRay` → `pathTrace` → firefly clamp → NaN/Inf guard → `imageLoad`/`imageStore` accumulation into `u_image`.

**`pathTrace()` loop:** Russian Roulette (depth ≥ 2) → `traceRayEXT` into TLAS → volume march (AABB slab test → exponential free-flight → HG scatter or Beer-Lambert transmittance; scatter does NEE sun/point and skips surface via `continue`) → on miss: add sky/env radiance and write zeros to aux images → unpack thin payload, fetch all shading data → front/back-face detection → normal mapping via hardware sampler → write first-hit albedo/normal to OIDN aux images at depth 0 → emission MIS → material dispatch (thin glass, dielectric, mirror, Cook-Torrance GGX) → NEE (emissive triangles, point light, sun, env CDF) with balance heuristic MIS → VNDF specular or cosine diffuse sample for next bounce.

### `rt.rmiss` — Miss

Primary ray miss shader. Sets `g_payload.hit = 0u` to indicate no intersection.

**Payload:** `layout(location=0) rayPayloadInEXT HitPayload g_payload`

---

### `rt.shadow.rmiss` — Miss

Shadow ray miss shader. Clears the occlusion flag to indicate the light is visible.

**Payload:** `layout(location=1) rayPayloadInEXT uint g_shadowed`

**Algorithm:** `g_shadowed = 0u;` — rgen pre-sets it to 1; a miss means unoccluded.

---

### `rt.rchit` — ClosestHit

Records the closest triangle hit into the thin payload for rgen to consume.

**Payload:** `layout(location=0) rayPayloadInEXT HitPayload g_payload`

**Hit attribute:** `hitAttributeEXT vec2 g_barycentrics`

**Algorithm:** Sets `g_payload.hit = 1u`, records `gl_HitTEXT` as `t`, computes global triangle index via `instanceOffsets[gl_InstanceCustomIndexEXT] + uint(gl_PrimitiveID)`, stores barycentric u/v.

---

### `rt.rahit` — AnyHit

Handles alpha transparency and thin glass in the any-hit stage before a hit is accepted.

**Payload:** `layout(location=0) rayPayloadInEXT HitPayload g_payload`

**Algorithm:**
- Resolves global triangle index from `instanceOffsets[gl_InstanceCustomIndexEXT] + gl_PrimitiveID`.
- If `materialType == 3` (thin glass) and this is a shadow ray (`gl_RayFlagsTerminateOnFirstHitEXT`): calls `ignoreIntersectionEXT` — thin glass is transparent to shadow rays.
- For alpha-clipped geometry: interpolates UV, samples the alpha texture (dedicated map or diffuse .a channel based on `triAlphaTexIdx` encoding). If alpha < 0.5, calls `ignoreIntersectionEXT` to discard the intersection.
